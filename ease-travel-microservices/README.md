# EaseTravel Workspace

This repository is split into:

- **`backend/`** — Java Spring Boot microservices (API Gateway, User, Trip, Booking, Payment, Notification services)
- **`frontend/`** — Frontend application (placeholder for now)

## Quick Start

### Backend

```bash
cd backend
mvn clean install -DskipTests
docker-compose up --build
```
